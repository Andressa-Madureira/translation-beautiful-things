# Coisas Bonitas 🎵✨
Este projeto é a primeira criação pessoal que desenvolvi para colocar em prática os conhecimentos adquiridos em programação. Surgiu como uma atividade proposta pela minha professora de inglês: traduzir uma música, incluindo imagens. Aproveitei a oportunidade para aplicar o que havia aprendido em HTML, CSS, e JavaScript, criando uma experiência imersiva e interativa.

🌟 Funcionalidades
<ul>
  <li>Parallax Dinâmico: Imagens de fundo que mudam automaticamente</li>
  <li>Reprodutor de Áudio: Controle de música diretamente na página</li>
  <li>Animação de Texto: Aparência gradual dos textos com efeito fade-in</li>
  <li>Design Responsivo: Layout adaptado para diferentes tamanhos de tela</li>
</ul>

📂 Estrutura do Projeto
1. HTML
  <ul>
  <li>Estruturação semântica e inserção do áudio com controles</li>
  </ul>

2. CSS
  <ul>
  <li>Animações suaves e ajustes para dispositivos móveis</li>
  </ul>

3. JavaScript
 <ul>
  <li>Alternância automática de imagens no fundo</li>
  <li>Funções de controle de reprodução de música</li>
</ul>
